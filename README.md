# 몽캡쳐

화면의 원하는 부분을 골라 캡처하고, 캡처한 화면의 글자를 문자 인식(OCR)으로 읽어 클립보드에 넣을 수 있는 Windows 프로그램이다. 영역·창·스크롤 캡처, 캡처 기록, 화면 위 고정(핀)을 지원한다. 광고가 없다.

## 빌드

`build.bat`을 실행하면 `bin\몽캡쳐.exe`가 만들어진다. Windows 10/11 SDK(`Windows.winmd`)와 .NET Framework 4.x 컴파일러(`csc.exe`)가 필요하다. 공개 저장소의 자동 빌드(GitHub Actions)도 같은 스크립트를 쓴다.
